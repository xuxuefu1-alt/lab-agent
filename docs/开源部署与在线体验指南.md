# 零费用在线体验部署指南

本方案在各平台免费额度内打通前端、Agent、MySQL 兼容数据库、Redis Checkpoint、RAG 和模型调用。它提供完整功能链路，但免费服务有休眠、配额和可用性限制，不提供企业生产 SLA。

## 架构

```text
Render Static Site（前端）
  -> Render Free Web Service（FastAPI，闲置休眠）
     -> TiDB Cloud Starter（MySQL 协议，业务数据）
     -> Redis Cloud Free（Redis Stack 搜索索引，Checkpoint）
  -> Qdrant Cloud Free（RAG 向量数据与免费多语言推理）
     -> Gemini API Free Tier（意图识别、Agent 对话与工具调用）
```

后端移除了 Chroma 和本地 SentenceTransformer，避免下载模型与占用免费实例内存。向量生成使用 Qdrant Cloud 的免费多语言模型，不调用 Gemini Embedding；Qdrant 不可用时，RAG 会回退到仓库知识文档上的本地 BM25 检索。SQLite 仅用于 CI 隔离测试；生产配置要求 MySQL 和 Redis。

## 1. 创建免费云端服务

### TiDB Cloud Starter

创建 MySQL-compatible Starter 集群和应用数据库用户，将 monthly spending limit 设为 `0`，按 TiDB 控制台提供的 MySQL 连接参数配置 `mysql_url`。TiDB 使用 MySQL 协议，项目继续使用 SQLAlchemy + PyMySQL。免费额度用尽时连接会被限制；不要启用付费超额计费。仅导入合成体验数据，不导入个人敏感数据。

```text
mysql+pymysql://<user>:<url-encoded-password>@<host>:<port>/<database>?ssl_verify_cert=true&ssl_verify_identity=true
```

### Redis Cloud Free

创建免费数据库并复制带 TLS 的连接 URI。LangGraph RedisSaver 需要 Search 索引命令；部署时会运行 `RedisSaver.setup()`，如果所选免费数据库不支持 `FT.CREATE`，后端启动会失败。

```text
rediss://default:<password>@<host>:<port>
```

### Qdrant Cloud Free

创建免费集群，取得 HTTPS URL 和 API Key。知识文档首次查询时会被分块、用 Qdrant Cloud 免费多语言模型向量化并写入 Qdrant；免费集群被暂停或不可用时，系统回退到本地 BM25 检索。

### Gemini API Free Tier

在 Google AI Studio 创建 API Key，保持在免费层且不要启用付费计费。Gemini 免费配额有速率限制，适合公开体验的小流量。免费层的数据可能用于改进 Google 产品；只使用合成用户、预约和资源数据，不发送真实个人数据或密钥。

## 2. Render Blueprint

将 GitHub 仓库 `xuxuefu1-alt/lab-agent` 的 `master` 分支导入 Render Blueprint，并选择免费后端计划。当前 `render.yaml` 默认使用 Gemini OpenAI 兼容端点和 `gemini-3.1-flash-lite`。

后端需要填写以下 `sync: false` 变量：

- `mysql_url`：TiDB 提供的 MySQL 连接串。
- `REDIS_URL`：Redis Cloud 的 TLS URI。
- `QDRANT_URL`：Qdrant HTTPS 集群地址。
- `QDRANT_API_KEY`：Qdrant API Key。
- `LLM_API_KEY`：Gemini API Key。
- `CORS_ORIGINS`：前端 Render HTTPS 域名。

前端变量：

- `VITE_API_BASE_URL=https://<backend-service>.onrender.com/api`

只有确认各服务都处在免费额度内后再 Apply。不要选择付费实例，不要创建持久盘。

## 3. 数据与文件持久化

业务记录存于 TiDB，Checkpoint 存于 Redis Cloud，向量知识存于 Qdrant；它们不依赖 Render 本地文件系统。当前上传接口仍写本地临时目录，Render 免费实例重启/重新部署后上传文件会丢失；它不是永久文件存储。免费体验中不要承诺上传文件长期保存。

本地 MySQL 地址为 `127.0.0.1`，Render 无法访问。可以用 MySQL 工具迁移合成体验数据：

```powershell
mysqldump --host=127.0.0.1 --port=3306 --user=<本地用户> -p --single-transaction --default-character-set=utf8mb4 lab_agent > lab_agent.sql
mysql --host=<TiDB主机> --port=<TiDB端口> --user=<TiDB用户> -p --ssl-mode=VERIFY_IDENTITY <TiDB数据库名> < lab_agent.sql
```

不要把电脑上的 MySQL 端口暴露到公网，也不要把导出文件提交到仓库。

## 4. 部署验收

1. 确认 Render 后端状态为 Live；免费服务休眠后，首次请求会有冷启动等待。
2. 打开 `https://<backend-service>.onrender.com/healthz`，确认返回 200。
3. 通过前端注册或预置体验用户登录。
4. 验证用户/资源查询、RAG 问答、预约查询/创建/取消、多意图请求、会话记忆和 SSE。
5. 在 TiDB 查看业务记录，在 Redis 检查点和 Qdrant 集合中确认对应状态已保存。

## 5. 免费额度边界

- Render Free 会休眠，文件系统不是可靠持久盘；免费方案不保证常驻、低延迟或 SLA。
- TiDB、Redis Cloud、Qdrant 和 Gemini 都有免费配额、连接数或速率限制；超出额度后可能拒绝请求或要求升级。
- Qdrant 免费集群长期无活动时可能暂停；系统会回退到本地 BM25，但语义检索质量会降低。
- GitHub Actions 只负责构建和测试，不会消除托管平台、数据库和模型服务的免费额度限制。
