# 开源部署与在线体验指南

本文用于把项目发布到 GitHub/Gitee，并提供无需购买服务器的在线体验入口。

## 一、本地完整链路

### 1. 后端

后端支持两种数据库模式：

- 本地开发默认 SQLite，适合快速启动和调试。
- Docker Compose 使用 MySQL，模拟完整部署环境。

Redis 用于 LangGraph Checkpoint、幂等锁和跨请求状态；没有 Redis 时，开发模式会自动使用内存 Checkpoint，但多进程部署必须配置 Redis Stack。

```powershell
cd backend
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:mysql_url = "sqlite:///./lab_agent.db"
$env:REDIS_URL = "redis://:lag-dev-redis@127.0.0.1:6379/0"
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

验证：`http://localhost:8000/healthz` 应返回 `{"status":"ok"}`。

### 2. 前端

```powershell
cd fronted
npm ci
npm run dev
```

访问 `http://localhost:5173`。Vite 会把 `/api` 代理到 `http://127.0.0.1:8000`。

### 3. Docker Compose

```powershell
$env:LLM_API_KEY = "你的模型密钥"
docker compose -f docker-compose.demo.yml up --build
```

访问 `http://localhost:8080`。该模式包含 MySQL、Redis、FastAPI 和 Nginx 前端。

## 二、发布到 GitHub/Gitee

1. 创建公开 GitHub 仓库。
2. 推送项目代码和文档，不要推送任何 `.env` 文件。
3. 可选：在 Gitee 创建镜像仓库，保留现有远程仓库用于国内访问。
4. 在仓库 Settings 中配置 Actions 所需的 Secret，不把密钥写入 YAML。

## 三、Render 在线体验

根目录的 `render.yaml` 会创建：

- `lab-agent-backend`：Python Web Service，健康检查 `/healthz`。
- `lab-agent-frontend`：Static Site，构建 Vue 前端。

Render Demo 后端默认使用 SQLite 和内存 Checkpoint，不需要先购买数据库和 Redis。部署时只配置：

- `LLM_API_KEY`：模型服务密钥。
- `CORS_ORIGINS`：前端站点域名。
- 前端 `VITE_API_BASE_URL`：后端域名加 `/api`。

如果要接近生产环境，应把 `mysql_url` 换成托管 MySQL/PostgreSQL，把 `REDIS_URL` 换成 Redis Stack，并将 `APP_ENV` 设置为 `production`。

## 四、持续更新

推荐流程：

```text
feature 分支开发
  -> 本地 pytest 与 npm run build
  -> Pull Request
  -> GitHub Actions 质量门禁
  -> 合并 master
  -> Render 自动重新部署
```

Render 免费服务可能休眠，首次访问会有冷启动延迟。面试展示时建议先打开健康检查接口唤醒服务，再进入前端。

## 五、上线前检查

- [ ] `backend/.env` 没有进入 Git。
- [ ] 模型密钥只配置在 Render Secret 或本地环境变量。
- [ ] `/healthz` 返回 200。
- [ ] 登录、用户查询、预约查询、预约取消和多意图请求均完成验证。
- [ ] Redis Stack 在多实例环境可访问。
- [ ] 生产数据库已开启备份与连接池限制。
- [ ] 审计日志、指标和链路追踪已接入监控平台。
